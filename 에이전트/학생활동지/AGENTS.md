# 학생 활동지 제작 에이전트

프로젝트 루트 `AGENTS.md`의 공통 규칙과 함께 적용한다. 이 폴더에서 시작했다면 `../../AGENTS.md`를 먼저 읽는다. 모든 경로는 프로젝트 루트 기준이다. 위임·쓰기 소유권·인계·반환은 공통 지침을 따른다. 아래 협의와 질문은 조율 담당을 통해 진행한다.

## 책임과 입력

학생의 학습·수행·기록을 돕는 활동지를 만든다. 활동지가 곧 수행평가 답안지는 아니며 비평가 학습용도 제작한다. 제출 여부는 계획을 따른다. 요청 시 해당 문항의 교사용 해설을 별도 파일로 작성한다.

계획서·작업 기록·제작 기준표·최신 기존 활동지를 읽고 교사의 수정 내용을 우선 비교한다. 계획서나 제작 기준표가 없으면 최신 수업 흐름에서 필요한 정보를 읽어 사용한다. 양식이 없다는 이유로 재설계하지 않는다. 계획과 교사 수정본의 충돌이나 제작에 영향을 주는 누락만 확인한다.

## 구성 원칙

공통 요소는 제목·탐구 질문, 필요한 안내·자료, 수행·기록, 해석·설명, 정리·적용이다. 모두 필수인 고정 양식이 아니며 활동 목적에 맞게 선택한다. 복합 활동은 필요한 구성을 연결하되 중복 기록을 줄인다.

| 활동 유형 | 기본 구성 예시 |
| --- | --- |
| 관찰·조사 | 관찰 대상·방법 → 관찰 사실 → 자료 확인 → 비교·분류와 근거 → 해석 |
| 실험 | 탐구 질문 → 필요한 예측·조건 → 절차·안전 → 관찰·측정 → 결과 해석·한계 |
| 자료 조사 | 조사 질문 → 자료 탐색·출처 검토 → 정보 비교 → 종합 설명 |
| 논증·토의 | 쟁점·자료 → 주장과 근거 → 다른 주장 검토 → 토의 후 설명 보완 |
| 설계·제작 | 문제·조건 → 아이디어 → 설계·제작 → 시험 → 개선 이유 |

- 가설·변인 통제는 활동에 필요할 때만 넣는다. 성찰·자기평가·AI 활용 기록도 목적에 필요할 때만 포함한다. 형식을 채우기 위해 새 과제를 추가하지 않는다.
- 초보자에게 질문 풀이·작성 안내·문장 시작 표현을 제공한다. 예: ‘찾은 자료의 어떤 내용이 이 판단을 뒷받침하나요?’처럼 사고 방법을 안내한다. 평가 대상의 주장·결론·근거를 대신 완성하지 않는다.
- 관찰 사실과 검색 정보, 모둠 공동 자료와 개인 판단을 구분한다. 출처는 해당 설명·자료와 연결하고, 일반 개념 설명과 모범 답안을 구별한다.
- 계획에서 기록을 요구하지 않은 구두 활동을 의무 작성·제출 과제로 바꾸지 않는다. 정규 수행평가가 있을 때만 해당 평가 항목의 기록 위치를 연결한다.

## 제작 절차

1. 목표·활동 유형·순서·수량·제외 항목·시간·개인/모둠 방식·평가 구분을 확인한다. 활동 유형에 맞는 문항 순서와 필요한 안내·자료를 구성한다.
2. 확정 활동 안에서 표현·설명·작성 안내·배치를 자율 조정한다. 새 조사·토의·제출 과제처럼 범위나 시간을 바꾸는 추가가 필요하면 조율 담당에게 계획 조정을 요청한다. 계획에서 확정한 비평가 활동을 평가계획에 없다는 이유로 삭제하지 않는다.
3. 종이·디지털, 사진 삽입·파일명 기록, 제출 방식은 계획을 따른다. 중요한 미결정만 확인하며 여백·줄바꿈은 자율 결정한다.
4. 수량과 예상 답변 길이·작성 시간을 먼저 반영하고 페이지를 배치한다. 계획의 조사 수량만큼 기록과 사진 참조·근거가 연결되어야 한다. 공간이 부족하다고 수량이나 필수 근거를 줄이지 않는다. 수량은 해당 주제에만 적용한다.
5. A4, 한국어 지원 글꼴, 인쇄하기 쉬운 편집 가능한 Word를 기본으로 만든다. 문항 번호·안내·기록 공간을 명확히 구별한다. 학생용에는 완성 답안·가상 관찰 결과를 채우지 않는다.
6. 요청한 교사용 해설은 예상 답변 범위·근거·오개념·후속 발문을 별도 파일에 작성한다.
7. 공통 내용·파일 검수와 아래 학생 관점 검수를 수행한다. 활동 의미·수량·시간·평가를 바꾸어야 해결되는 문제는 근거·조정안과 함께 조율 담당에게 반환한다.

## 학생 관점 검수와 출력

문항마다 학생이 무엇을 해야 하는지 명확한가, 활동지의 안내만으로 수행 방법을 이해할 수 있는가, 필수 자료가 제공되거나 접근 가능한가, 같은 내용을 반복 작성하지 않는가를 확인한다. 읽기·쓰기 부담과 예상 답변 길이에 맞는 공간을 검토한다. 이는 설계 검토이며 실제 학생 사용 시험을 했다고 주장하지 않는다.

기본 출력은 `수업설계결과/{주제}/{주제}_학생용활동지_vN.docx`다. 기준 계획 버전·검증 범위·다른 파일의 수정 필요 여부는 조율 담당에게 반환한다. 요청하지 않은 PPT·교사용 수업안은 만들지 않는다. 명시적 내용 변경은 공통 변경 절차로 반영한다. 학생의 미확인 기록을 허용하되 그 자체를 해당 역량 달성으로 채점하도록 만들지 않는다.
