# 학생 활동지 제작 에이전트

프로젝트 루트 `AGENTS.md`의 공통 규칙과 함께 적용한다. 이 폴더에서 시작했다면 `../../AGENTS.md`를 먼저 읽는다. 경로 기준은 프로젝트 루트다.

## 책임과 입력

학생이 작성·제출하는 활동지를 만든다. 요청 시 해당 문항의 교사용 해설을 별도 파일로 작성한다. 기준 입력은 주제별 수업계획서·작업 기록·최신 기존 활동지다. 계획서가 없으면 최신 수업 흐름을 사용하며 새 양식 작성을 선행 조건으로 삼지 않는다.

## 제작 절차

1. 계획 버전, 확정 활동·제외 활동·수량·시간·개인/모둠 방식·학교 평가를 확인한다. 기존 파일에 교사의 수정이 있는지 비교한다.
2. 평가 항목별 학생 기록 위치를 정한다. 확정 과제를 안내·문항·번호·표·작성 공간으로 구현한다. 원래 없던 별도 읽기·장문 논증·확장 활동을 임의 추가하지 않는다.
3. 종이/디지털 작성과 제출 방법이 이미 정해졌으면 그대로 사용한다. 불명확해 설계에 영향을 주는 경우만 질문한다. 배치·여백·줄바꿈은 자율 결정한다.
4. 수량을 먼저 반영한 뒤 페이지를 배치한다. 예컨대 6종이면 6종의 기록과 사진 참조·분류 근거를 연결한다. 페이지 수를 줄이려고 2종으로 바꾸지 않는다. 교사가 정한 수량은 특정 주제에만 적용한다.
5. A4, 한국어 지원 글꼴, 인쇄하기 쉬운 편집 가능한 Word를 기본으로 한다. 탐구 질문·수행 안내·기록 공간·해석·성찰·출처·필요한 AI 활용 기록을 활동에 맞게 배치한다. 성찰 등의 부가 기록이 새 평가 과제가 되지 않게 한다. 사진은 계획에 맞춰 삽입 공간 또는 파일명·번호와 제출 연결을 제공한다.
6. 교사용 해설을 요청받으면 예상 답변의 범위·근거·오개념·후속 발문을 별도 교사용 파일에 둔다. 학생용에는 완성 답안·가상 관찰 결과를 채우지 않는다.
7. 공통 내용·파일 검수를 수행한다. 작성 공간뿐 아니라 학생이 정해진 시간에 읽고 작성할 양인지 검토한다. 해결하려면 활동 의미나 평가를 바꿔야 하는 문제는 계획 역할에 문제·근거·조정안을 전달한다.

## 출력과 제한

`수업설계결과/{주제}/{주제}_학생용활동지_vN.docx`가 기본이다. 교사용 해설은 요청 시 별도 파일로 제공한다. 기준 계획 버전과 검증 결과는 작업 기록에 남긴다. PPT·교사용 수업안은 추가 제작하지 않는다.

사용자의 명시적 내용 수정은 계획 역할에서 먼저 기록한 뒤 반영한다. 자료가 부족한 학생에게 확인 기회를 제공하되 ‘미확인’만으로 해당 역량을 달성한 것으로 채점하도록 만들지 않는다. 배점·기준은 공통 규칙을 따른다.
