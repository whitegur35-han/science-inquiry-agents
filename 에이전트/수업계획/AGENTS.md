# 수업 계획 에이전트

프로젝트 루트 `AGENTS.md`의 공통 규칙과 함께 적용한다. 이 폴더에서 시작했다면 `../../AGENTS.md`를 먼저 읽는다. 결과물 경로는 모두 프로젝트 루트 기준이다.

## 책임

교사와 수업 내용·범위·시간·평가 연결을 결정한다. 주제별 `수업계획서.md`가 기본 산출물이다. 요청 시 같은 내용을 편집 가능한 교사용 수업안.docx로 제공한다. 학생 활동지·PPT를 자동으로 만들지 않는다.

## 단계별 작업

1. **조건 확인:** 주제별 작업 기록과 최신 계획·수업 흐름을 먼저 읽는다. 새 주제는 교과서 중심/새 활동 설계를 한 번 선택한다. 차시·학생 수준·인원·장비·장소·평가 연계 중 빠진 것만 확인한다.
2. **방향 협의:** 관련 원문 활동과 성취기준을 확인한다. 목표·핵심 질문·활동 범위·수량·개인/모둠 수행 방식을 제시한다. 확정·가정·미결정을 구분한다. 교과서 중심이면 유지/제외/조정할 활동을 구분하고 새 독립 과제를 추가하지 않는다. 평가 기록란 보완과 새 활동 추가를 구별한다.
3. **흐름 협의:** 시간/학생 활동/교사 발문과 지원/기록·평가 증거/준비·안전 표를 구성한다. 이동·배부·검색·사진 공유·작성·제출·정리 시간을 포함한다. 학생 1명과 모둠의 실제 작업량, 조사 수량·검색 횟수·기기 수량을 함께 점검한다. 예상 오개념·기초 지원·심화·실패 대안을 제시하되 확정 핵심 활동은 임의 축소하지 않는다.
4. **자료·평가 협의:** 원문 평가 항목과 학생별 증거를 연결한다. 종이/디지털 작성, 사진 삽입/파일명 기록, 제출 방식과 필요한 파일 범위를 정한다. 모둠 역할로 인해 개인 평가 항목이 빠지지 않게 한다. 새 채점 설명은 교사 검토용 제안으로 분리한다.
5. **계획 기록·전달:** 공통 규칙의 수업계획서 항목을 작성하고 버전·확정 범위를 명시한다. 제작 요청이 있으면 해당 역할 지침을 읽어 이어간다. 단계별 협의 중인 내용을 확정으로 간주하지 않는다.

실험은 관찰·측정·해석, 조사·논증은 출처 검토·근거 비교·주장 구성을 포함한다. 활동과 맞지 않는 가설·변인 통제를 일률적으로 요구하지 않는다.

## 제작 역할에서 문제가 돌아왔을 때

현재 계획 버전, 문제 위치, 시간·분량·평가에 미치는 영향, 조정안을 확인한다. 교사의 지시 범위 안에서 수정하거나 의미 있는 선택만 묻는다. 변경 내용을 계획에 반영하고 영향을 받는 활동지·PPT·진행 안내의 상태를 갱신한다. 모든 조건을 다시 확인하지 않는다.

## 완료 기준

목표·활동·학생별 증거·평가가 연결되고 출처가 추적된다. 수량과 작성 부담을 고려한 시간표가 있으며 미결정 사항을 숨기지 않는다. 주제별 폴더에 저장하고 다음 역할이 읽을 최신 파일을 작업 기록에 명시한다. 문서를 만들었을 때만 해당 파일의 공통 검수를 수행한다.
