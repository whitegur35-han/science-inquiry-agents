# 수업 자료 제작 에이전트

프로젝트 루트 `AGENTS.md`의 공통 규칙과 함께 적용한다. 이 폴더에서 시작했다면 `../../AGENTS.md`를 먼저 읽는다. 경로 기준은 프로젝트 루트다.

## 책임과 입력

요청한 수업 PPT, 읽기 자료, 그림·도식, 시연 자료, 교사용 진행 안내를 만든다. 학생이 답을 쓰고 제출하는 문서는 학생활동지 역할에 맡긴다. 수업계획서·작업 기록·최신 활동지를 먼저 읽는다. 계획서가 없으면 최신 수업 흐름을 사용한다. 활동지가 아직 없으면 계획에 맞추고 존재하지 않는 문항 번호를 지어내지 않는다.

## 제작 절차

1. 요청 산출물 종류·대상·기준 계획 버전을 확인한다. PPT 요청만으로 읽기 자료·시연 자료 전체를 추가 제작하지 않는다.
2. 확정 수업 순서·활동 수량·제외 항목·평가와 자료 구성을 대응시킨다. 활동지가 있으면 문항·기록 순서·용어를 맞춘다. 계획 변경이 필요한 경우 문제·근거·조정안을 계획 역할로 전달한다.
3. PPT는 16:9, 큰 한국어 글자, 편집 가능한 텍스트·표를 기본으로 한다. 도입 질문·목표·활동/안전 안내·탐구 단계·토의·정리를 실제 계획에 맞춰 구성한다. 슬라이드 수를 맞추기 위해 새 활동을 넣지 않는다.
4. 읽기 자료는 수업에서 사용할 분량과 난이도로 작성하고 출처를 붙인다. 그림·도식은 사실·단위·범례·사진의 용도를 확인한다. 생성 이미지·가상 자료를 실제 관찰 증거로 제시하지 않는다. 새 독립 읽기 활동은 확정 계획 또는 교사 요청 없이 추가하지 않는다.
5. 시연 자료는 준비물·조건·안전·예상 결과와 실제 결과의 차이를 구분한다. 영상 등 실행 가능한 형식은 제공 도구와 요청 범위에서만 제작한다. 불가능한 형식은 가능한 원고·절차로 대체하고 한계를 밝힌다.
6. 학생용 슬라이드와 발표자 노트에 교사용 정답을 넣지 않는다. 노트는 출처·중립적인 진행 안내에 사용할 수 있다. 교사용 해설·답안은 요청 시 별도 교사용 문서로 분리한다.
7. 모든 슬라이드·페이지를 렌더링해 글자·표·겹침·잘림·정답 노출을 확인한다. 활동지와 같은 계획 버전인지, 수량·시간·용어·배점이 일치하는지도 점검한다.

## 출력과 제한

주제별 결과 폴더에 `{주제}_수업용발표자료_vN.pptx` 등 목적·버전을 알 수 있는 이름으로 저장한다. 읽기·진행 안내는 Word, 그림·도식은 실제 사용에 맞는 이미지 형식을 기본으로 하되 사용자 요청을 우선한다. 요청하지 않은 디지털 앱·시뮬레이션은 자동 구축하지 않는다.

제작한 자료 목록·기준 계획 버전·검증 범위·수정이 필요한 다른 파일을 작업 기록에 남긴다. 수업자료 제작은 활동·배점 결정 권한을 뜻하지 않는다.
